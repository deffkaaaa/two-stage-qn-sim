# Імітаційна модель двостадійної обробки деталей з браком (ММО)

Курсова робота з моделювання систем, завдання B1. Власний алгоритм імітації мовою Java
без сторонніх бібліотек (потрібен лише JDK 17+).

## Структура

| Клас                                               | Призначення                                                            |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| `Params`                                           | вхідні змінні та параметри (таблиці 1.1-1.3)                           |
| `Sampler`, `RandomSampler`, `DeterministicSampler` | джерело випадковості; детермінований режим для верифікації             |
| `Part`                                             | деталь (тип θ: 1 - перше проходження, 2 - повторне)                    |
| `PartQueue`                                        | черга необмеженої місткості, статистика за нерівними інтервалами часу  |
| `Element`, `Source`, `Server`                      | елементи, що породжують події (I0, P1, P2, S1, S2)                     |
| `Dispatcher`                                       | пристрої D0, DS з нульовим часом і блокуванням маршрутів               |
| `Model`                                            | мережа, умови блокування (2.1)-(2.7), просування часу, збір статистики |
| `Results`, `EventLog`, `Main`                      | вихідні змінні, протокол подій, запуск                                 |

## Запуск

```
mvn package
java -cp target/classes ua.kpi.modsim.Main trace 300 0.5 0.5 3 protocol.txt   # детермінований прогін
java -cp target/classes ua.kpi.modsim.Main run 100000 0 3 1                   # T warmup H seed
```

У IntelliJ IDEA: File -> Open -> оберіть `pom.xml` (Open as Project), запустіть `Main`.
